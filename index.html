配套代码：本教程所有示例都在 demo/ 项目里。 进入该目录执行 npm install && npm run dev， 再打开 http://localhost:3000 就能逐个点开看效果。 每个页面的详细说明见 demo/README.md。

建议的学习顺序

按编号从头读。第一章的「渲染策略」是地基——它回答了 「HTML 到底什么时候生成」，后面所有关于数据、缓存、性能的话题都建立在它之上。

每章的建议流程是：读 HTML 讲解 → 打开 demo 里对应的路由动手验证 → 回到自己的项目里用一次。每章的讲解末尾都列出了 demo 的文件路径。

验证 SSG / ISR 时记得用 npm run build && npm start， 开发模式为了热更新会每次重新渲染，看不出静态缓存的效果。
